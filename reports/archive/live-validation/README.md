# Archived live validation reports

This directory holds historical live-validation JSON outputs that are no longer the
active source of truth for the current workflow.

Archive a report here only when one of the following is true:
- a newer approved report supersedes it
- the report is retained only for historical reference
- its actionable guidance has already been absorbed into runbooks, prompts, or rules

Do not treat archived reports as the current gate input unless an operator explicitly
chooses to review historical evidence.
